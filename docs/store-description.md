# MadDragon — Steam Store Description

## Short Description (up to 29 words)

Deploy knights, archers, and mages to hold five waves of invaders — then attack your own base to find its weak spots. A medieval strategy game built for short sessions.

---

## Full Description

**MadDragon** is a medieval real-time strategy game designed for players who want meaningful decisions, not just spectating. In each session you check the incoming threat, pick your unit lineup and spells, watch the battle resolve, and read the result — then redesign your strategy for the next run.

Every choice has a consequence you can see immediately. Place your knight wrong and the archers get flanked. Use your spell too early and the final wave overwhelms you. The result screen tells you what went wrong, and the next run is right there waiting.

**The core loop:**
1. Survey — current threats, available resources, incoming wave composition
2. Choose — pick from up to 5 clear actions: unit deployment, spell selection, building upgrade, or formation shift
3. Result — combat, score, and resource state update immediately after your decision
4. Prepare — use what you learned to set up the next round

**Five waves, increasing pressure:**
Wave 1 opens with five basic enemy knights. By wave 5 you face thirteen units across every enemy type. Survive all five waves and hold for 22 seconds — that is a win.

**Build your own trap — then attack it:**
Set up your defensive base, then switch to attack mode and run your own assault. The result is a weak-point heatmap of your own defenses. Use it to redesign before the next wave hits.

**Units and magic:**
- Knight — melee tank, the first line of defense
- Archer — ranged dealer, unlocked at Barracks Lv1
- Mage — area-effect magic, unlocked at Barracks Lv2
- Spells — 2 to 3 combat spells per engagement, chosen before the wave

**Session design:**
A single wave cycle takes under 15 minutes. The game is designed around 5–15 minute sessions with a clear endpoint every run — no open-ended idle loop, no energy timer.

## Key Features

- Five-wave escalating defense with real-time battle resolution
- Unit upgrades via Barracks leveling (Knight baseline → Archer → Mage)
- Attack-your-own-base mode for defensive gap analysis
- Intel panel: enemy wave threat summary, approach routes, recommended counters
- Raid loss calculator with base protection rate and loot-at-risk display
- Result screen with next-run hints
- Singleplayer, offline — no energy system, no wait timers
