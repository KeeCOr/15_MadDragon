# MadDragon — Steam 스토어 설명 (한국어)

## 짧은 설명 (최대 29단어)

기사·궁수·마법사를 배치해 5파 침략을 막아라. 직접 만든 기지를 공격해 약점을 찾는 중세 전략 게임. 짧은 세션에 딱 맞게 설계됐다.

---

## 전체 설명

**MadDragon**은 "그냥 보고만 있지 않아도 되는" 중세 실시간 전략 게임입니다. 매 세션마다 적 위협을 확인하고, 유닛과 마법을 선택하고, 전투 결과를 읽고, 다음 전략을 다시 세웁니다.

모든 선택의 결과를 즉시 볼 수 있습니다. 기사를 잘못 배치하면 궁수가 측면을 뚫립니다. 마법을 너무 일찍 써버리면 마지막 파에서 압도됩니다. 결과 화면이 무엇이 잘못됐는지 알려주고, 다음 판은 바로 기다리고 있습니다.

**핵심 루프:**
1. 확인 — 현재 위협, 보유 자원, 다가오는 웨이브 구성을 파악
2. 선택 — 유닛 배치, 마법 선택, 건물 업그레이드, 대형 변경 중 최대 5개의 명확한 행동 중 결정
3. 결과 — 선택 직후 전투·점수·자원 상태가 즉시 변화
4. 준비 — 얻은 정보로 다음 라운드를 설계

**5파, 점점 커지는 압박:**
1파는 기사 5기로 시작합니다. 5파에서는 모든 적 유형을 포함한 13기가 밀려옵니다. 5파 전부 격퇴 후 22초를 버티면 승리입니다.

**직접 만든 함정을 직접 공격하라:**
수비 기지를 설계한 뒤 공격 모드로 전환해 내 기지를 직접 공략합니다. 결과로 내 방어선의 약점 히트맵을 얻습니다. 다음 웨이브 전에 재설계하는 데 활용하세요.

**유닛과 마법:**
- 기사 — 근접 탱커, 첫 번째 방어선
- 궁수 — 원거리 딜러, 훈련소 Lv1 해금
- 마법사 — 광역 마법 딜러, 훈련소 Lv2 해금
- 마법 — 전투당 2~3개 장착, 웨이브 시작 전 선택

**세션 설계:**
웨이브 한 사이클은 15분 이내에 끝납니다. 5~15분 세션에 맞게 설계됐고, 매 판이 명확한 마무리 지점을 가집니다. 무한 방치 루프도, 에너지 타이머도 없습니다.

## 주요 기능

- 실시간 전투 해결 방식의 5파 에스컬레이팅 방어
- 훈련소 레벨업을 통한 유닛 해금 (기사 기본 → 궁수 → 마법사)
- 내 기지 공략 모드 — 방어 취약점 분석
- Intel 패널 — 적 웨이브 위협 요약, 진입 경로, 추천 카운터 유닛
- 레이드 손실 계산기 — 기지 보호율과 위험 자원 표시
- 다음 판 힌트가 포함된 결과 화면
- 싱글플레이어, 오프라인 — 에너지 시스템 없음, 대기 타이머 없음
