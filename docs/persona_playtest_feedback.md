# MadDragon 페르소나 재테스트 피드백

## 페르소나

- 이름: 한도윤
- 성향: 모바일 방어/약탈 RTS와 클래시류 성장 게임을 좋아한다.
- 기대: 전투가 끝났을 때 무엇을 잃었고 다음에 무엇을 고쳐야 하는지 바로 알고 싶어 한다.

## 2026-07-03 재테스트 피드백

- 이전 문제: 결과 화면이 승패와 보상만 보여줘서 방어 실패 후 왜 아픈지, 다음에 무엇을 해야 하는지 판단하기 어려웠다.
- 개선 확인: 결과 패널이 저장 자원 손실, 지갑 자원 손실, 총 손실, 다음 행동 힌트를 함께 표시하도록 연결됐다.
- 체감: 플레이어는 실패 직후 “본진 보호를 올릴지”, “전방 방어를 늘릴지”를 더 빨리 결정할 수 있다.
- 남은 아쉬움: Unity Test Runner XML이 생성되지 않아 자동 테스트 리포트는 아직 불완전하다. 또한 `TestBootstrap.cs` 안의 오래된 한글 깨짐 문구는 별도 정리가 필요하다.
